# Juice Shop DevSecOps

Projet de groupe DevSecOps autour de OWASP Juice Shop.

## Objectif

Construire une chaîne DevSecOps automatisée avec :

- Podman
- GitHub Actions
- Gitleaks et Trivy
- Semgrep et npm audit
- Kubernetes (minikube)
- Prometheus et Grafana
- Notifications Discord

## Équipe

- Chagdaly Abdelhamid : GitHub, pipeline et documentation
- Yahya : Podman, Gitleaks et Trivy
- Aimad : Kubernetes, supervision, Semgrep et npm audit

## Sécurité

Juice Shop est une application volontairement vulnérable.
Elle doit être utilisée uniquement dans un environnement local
ou contrôlé et ne doit pas être exposée librement sur Internet.
